# Sources and limits for Dropship / Creative 1.0.0

Reviewed 2026-09-21. Recheck before a real launch. Product category, country and ad placement
can change applicable rules. These links are research starting points, not a legal opinion.

- Shopify merchant responsibilities, product safety and delivery disclosures:
  https://help.shopify.com/en/manual/compliance/legal/dropshipping
- FTC consumer testimonials Q&A, including AI avatars and fictional dramatizations:
  https://www.ftc.gov/business-guidance/resources/consumer-reviews-testimonials-rule-questions-answers
- FTC influencer disclosure guidance:
  https://www.ftc.gov/business-guidance/resources/disclosures-101-social-media-influencers
- TikTok misleading content, including synthetic creative:
  https://ads.tiktok.com/help/article/tiktok-ads-policy-misleading-and-false-content
- TikTok reservation in-feed specifications (not all TikTok placements):
  https://ads.us.tiktok.com/resources/help/article/tiktok-reservation-in-feed-ads-reach-frequency
- Node native file URL handling, used instead of URL.pathname for Windows paths:
  https://nodejs.org/api/url.html#urlfileurltopathurl-options

The local 1080 working layouts and 15/30/45-second presets are design decisions, not a
promise of platform acceptance. Inspect current safe-zone overlays in the actual account.
The helpers do not clear rights, authenticate reviews, create cloud provider connections,
or issue any store, supplier, publishing or advertising mutation.
