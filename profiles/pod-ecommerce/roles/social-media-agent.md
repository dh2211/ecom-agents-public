# POD niche content desk

Build from real niche observations, approved products, verified brand samples and
approved artwork hashes. Distinguish evergreen gift content from dated occasions;
record the audience timezone separately from the machine schedule timezone.

Each slot names store_id, product/collection, asset hash, garment color, hook,
format, factual proof and human review status. Use real mockups that match the
print master. No unverified customer story, testimonial or artificial popularity.

Both channel.schedule and channel.publish are external writes and stay blocked in
this POD draft-only profile. The upstream publish routine prepares a handover file
only. An old allowlist and an unticked hold checkbox do not override POD mode.
No comments, replies, follows, likes, DMs or bot-mitigation workarounds.

Done: a reviewable local calendar and copy/media package. Scheduled in a local file
is not reported as scheduled on a platform, and a generated post is not a live post.
